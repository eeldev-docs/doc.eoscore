Plugin Modules​

ModuleDescription
EOSCoreBlueprint functions and async nodes for the EOS SDK interfaces (Auth, Connect, Sessions, Lobby, P2P, Stats, Leaderboards, Achievements, Player Data Storage, Title Storage, Ecom, Presence, Friends, UserInfo, UI, RTC, Chat, Anti-Cheat, Sanctions, Reports, Mods, Metrics, Custom Invites, Progression Snapshot)
OnlineSubsystemEOSCoreThe EOSCore Online Subsystem, NetDriver and socket subsystem for EOS P2P
EOSCoreWebBlueprint functions for the EOS Web API (Auth, Connect, Player Tickets, Sanctions, Anti-Cheat status, Voice)
EOSCoreSharedTypes shared between the modules

Online Subsystem Interfaces​

These are the IOnlineSubsystem interfaces the EOSCore Online Subsystem implements. Interfaces marked No return nullptr, use the EOSCore Blueprint functions for those features instead.

InterfaceImplementedNotes
IdentityYesLogin, logout, automatic login with -AUTH_TYPE
SessionYesEOS Sessions, plus LAN sessions. Join in the EOS overlay and accepted invites call OnSessionUserInviteAccepted
StatsYes
LeaderboardsYes
AchievementsYes
VoiceYesSee Voice Chat (OSS)
Store V2 / PurchaseOnly when started from the Epic Games Launcher (-EpicPortal)
FriendsYesFriends list, friend invites, blocked players. Needs an Epic Account login
PresenceYesSet and query presence, presence change notifications. Needs an Epic Account login
UserYesUser info (display names) and external account id mappings
External UIPartlyShowLoginUI (Account Portal), ShowFriendsUI (EOS overlay) and ShowWebURL. The other Show functions are not implemented
User Cloud, Shared Cloud, Title File, EntitlementsNoUse Player Data Storage, Title Storage and Ecom functions
Party, Groups, Chat, Messages, Events, Sharing, Time, Tournaments, Turn BasedNo
