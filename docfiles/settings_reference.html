Project Settings Reference

EOSCore is configured in Project Settings > Plugins > EOSCore Plugin. The settings are saved in Config/DefaultEngine.ini under the section [/Script/OnlineSubsystemEOSCore.EOSCoreSettings].

EOS Configurations​

You can add several configurations, for example one for the client and one for a dedicated server. The plugin picks one when it starts:

  1. The configuration named by the -EOSConfig= command line argument, if it exists.
  2. Otherwise the configuration named by Default Configuration Name.

If no configuration matches, the plugin does not initialize and the log shows GetEOSConfig(): Did not find any EOS Configuration.

SettingDescription
Config NameName used by Default Configuration Name and -EOSConfig=
Product IdFrom the Developer Portal, Product Settings
Sandbox IdFrom the Developer Portal. Overridden by -epicsandboxid=
Deployment IdFrom the Developer Portal. Overridden by -epicdeploymentid=
Client IdClient created in Client & Policy Settings. Client ids start with xyz
Client SecretSecret of that client
Encryption KeyExactly 64 hexadecimal characters (a 256 bit key). Used to encrypt Player Data Storage files. The default value 1111… is only a placeholder, generate your own key before you ship
Enable RTCEnables the RTC (voice) interfaces. Turn it off if you don't use EOS voice
warning

The Client Secret is stored in DefaultEngine.ini and ships with your game. Use a client policy that only allows what the game client needs, and a separate configuration with its own client for servers.

Steam Integrated Platform​

Registers Steam as an Integrated Platform when the EOS platform is created (Windows, Linux and Mac). EOS then mirrors presence and sessions to Steam and follows the Steam login state.

Settingini keyDescription
Enable Steam Integrated PlatformbEnableSteamIntegratedPlatformTurns the integration on. Default false
Steam Major VersionSteamMajorVersionMajor version of the Steamworks SDK the game is built with. Default 1
Steam Minor VersionSteamMinorVersionMinor version of the Steamworks SDK, for example 64 for UE 5.8 (Steamworks 1.64). Must be set, the integration is skipped while it is 0
Steam Disable Presence MirroringbSteamDisablePresenceMirroringStops EOS from copying presence to Steam
Steam Disable SDK Managed SessionsbSteamDisableSDKManagedSessionsStops EOS from creating Steam sessions for EOS sessions and lobbies
Steam Prefer Integrated IdentitybSteamPreferIntegratedIdentityShows Steam names instead of Epic names where both exist

The Steam library is managed by the game, so the Steam Online Subsystem (or your own code) must initialize Steam before EOSCore creates the platform.

ini-only Settings​

These keys are not shown in Project Settings. Add them to the same section in DefaultEngine.ini.

[/Script/OnlineSubsystemEOSCore.EOSCoreSettings]
; Set to false to disable the EOSCore Online Subsystem
bEnabled=true
; Folder the EOS SDK uses for its cache (ignored on Android)
OverrideCacheDir=D:/MyGameCache
; Log level of the EOS SDK's own messages (non-Shipping builds only)
SDKLogLevel=Warning
; Seconds EOS retries network tasks before they fail
TaskNetworkTimeoutSeconds=10
ini keyDefaultDescription
bEnabledtrueEnables the EOSCore Online Subsystem. The older sections [/Script/EOSCore.EOSCoreSettings] and [EOSCore] are still read if this key is missing
OverrideCacheDirUser folder /CacheDirCache folder for the EOS SDK. Android always uses the app's internal files folder
SDKLogLevelVeryVerboseOff, Fatal, Error, Warning, Info, Verbose or VeryVerbose. Lower it if the EOS SDK messages flood your log. Not used in Shipping builds, where SDK logging is off
TaskNetworkTimeoutSeconds10How long EOS retries a network task (for example a login while offline) before the callback fails
