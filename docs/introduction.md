# Introduction

**EOSCore** brings [Epic Online Services](https://dev.epicgames.com/docs) (EOS) to Unreal Engine. It exposes the EOS SDK as Blueprint functions and async nodes, and adds an Online Subsystem (`EOSCore`) with a NetDriver for EOS P2P, so you can build online and multiplayer games without C++.

## Getting Started
1. [Install the plugin](./docfiles/getting_started/installing_plugin.md) and disable the engine's own EOS plugins
2. [Configure the Online Subsystem](./docfiles/getting_started/configuring_subsystem.md) in DefaultEngine.ini
3. [Create a client and a client policy](./docfiles/getting_started/setup_client_policy.md) in the Developer Portal and enter your credentials in [Project Settings](./docfiles/settings_reference.md)
4. [Log in](./docfiles/getting_started/auth/information.md). EOS requires a logged in user before you can use any other feature
